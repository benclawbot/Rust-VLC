# VLC runtime notices

The Windows and macOS installers include the unmodified VideoLAN VLC 3.0.24
runtime and its plugins for the matching CPU architecture. The Arch Linux
package depends on Arch's `libvlc` and `vlc-plugins-all` packages, which provide
the runtime and full plugin set through the system package manager.

VideoLAN distributes VLC under several open-source licenses. libVLC is LGPL
2.1-or-later, while individual VLC modules and bundled components retain their
own licenses. See the notices included in the VLC runtime and the upstream
[license information](https://www.videolan.org/legal.html). The corresponding
VLC 3.0.24 source release is available at
<https://download.videolan.org/pub/videolan/vlc/3.0.24/vlc-3.0.24.tar.xz>.

Runtime packages and downloads used by release packaging:

- Arch Linux: [libvlc](https://archlinux.org/packages/extra/x86_64/libvlc/) and [vlc-plugins-all](https://archlinux.org/packages/extra/x86_64/vlc-plugins-all/)

- Windows x86_64: <https://get.videolan.org/vlc/3.0.24/win64/vlc-3.0.24-win64.zip>
- macOS Apple Silicon: <https://download.videolan.org/pub/videolan/vlc/3.0.24/macosx/vlc-3.0.24-arm64.dmg>
- macOS Intel: <https://download.videolan.org/pub/videolan/vlc/3.0.24/macosx/vlc-3.0.24-intel64.dmg>
